# Security Policy

## Reporting a security issue

Please do not publish sensitive security details in a public issue.

If you discover a security-related problem, contact the repository owner privately through an appropriate GitHub contact method and include:

- a clear description of the issue;
- steps to reproduce it;
- the affected page or feature;
- the possible impact;
- any suggested fix, if known.

Please avoid accessing data that is not yours, disrupting the project, or testing in ways that could harm other users.

## Supported version

DevQuest is currently an early-stage project. Security fixes are applied to the latest version on the default branch.
