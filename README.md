# DevQuest

DevQuest is an open-source coding challenge platform built to help developers learn by solving practical problems and collaborating through GitHub.

## What is included in v1?

- Responsive landing page
- Beginner, Intermediate and Advanced coding quests
- Difficulty filtering
- Contribution workflow
- Dependency-free HTML, CSS and JavaScript

## Run locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/Codingapo/devquest.git
cd devquest
```

Then open `index.html`.

## How we develop DevQuest

We intentionally use a real GitHub workflow:

1. Open or choose an issue.
2. Create a focused branch.
3. Commit the implementation.
4. Open a pull request.
5. Review, improve and merge it.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution guide.
