# Contributing to DevQuest

Thanks for helping improve DevQuest.

## Contribution workflow

1. Choose or open an issue describing the change.
2. Create a focused branch such as `feature/new-challenge` or `fix/mobile-layout`.
3. Make and test your changes.
4. Commit with a clear message.
5. Open a pull request that explains what changed and references the issue.
6. Respond to review feedback and merge when the change is ready.

## Challenge contributions

A good challenge should include:
- a clear goal;
- expected input and output;
- a difficulty level;
- at least one example;
- no copied proprietary problem text.

## Pull request quality

Keep pull requests focused. A small PR that solves one issue well is easier to review and maintain than a huge unrelated set of changes.

Be respectful in issues, reviews, and discussions.
